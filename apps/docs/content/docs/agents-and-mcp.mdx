%product% is built headless first. Every capability of the console is an operation that the HTTP API, the `bandwise` CLI and the MCP server also expose, under the same permission checks. An agent can therefore build a set, run evals, publish and move it through rollout.

## The plan in brief

- **Agent tokens.** An agent acts as one user in one org, with scopes and a role ceiling. Its effective role is never higher than the user's own role in that org.
- **Agents propose, people approve.** High-risk moves by an agent, such as moving a set to `full`, wait for a person to approve them. Moves toward safety, such as pausing or rolling back, never wait.
- **MCP server.** A curated set of tools over the same operations, for agents that speak the Model Context Protocol.

This page will cover setup and the tool list when they ship.
